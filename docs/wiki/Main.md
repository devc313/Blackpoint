# Main

**Özet:** Uygulamanın entry point'i. eframeNativeOptions ile pencere oluşturur ve [[App]] modülünü başlatır.

**Kütüphaneler:** eframe

## Yapilandirma

- Pencere boyutu: 1320x820 (başlangıç), 960x680 (minimum)
- Custom window chrome (decorations kapalı)
- Resizable: true
- Başlık: "Blackpoint"

## Baglantilar

- [[App]] - BlackpointApp struct'ı
- [[Theme]] - configure_theme ile tema ayarları
